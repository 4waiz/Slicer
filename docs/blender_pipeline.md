# Blender Pipeline

Every 3D asset and every piece of 2D art in this game is generated by scripts
in `art/blender/`, driven through Blender MCP. Nothing was modelled by hand,
nothing was downloaded, and the whole library can be rebuilt from scratch at
any time by re-running the scripts.

## Files

| File | Role |
| --- | --- |
| `kanban_lib.py` | Shared helpers: palette, materials, manifold primitives, assembly, finalisation, GLB export |
| `build_01_core.py` | Hero structure, blade, blade FX, the four target pads |
| `build_02_library.py` | The 44 world assets: crystals, jelly, fruit, toys, machines, planets |
| `render_art.py` | Renders world banners and the store icon from the exported GLBs |
| `kanban_core.blend` | Saved scene for the hero structure, for reference/inspection |

To rebuild, exec `kanban_lib.py` then the build script in the same namespace:

```python
ns = {}
exec(open("art/blender/kanban_lib.py").read(), ns)
ns["EXPORT_DIR"] = "assets/models"
exec(open("art/blender/build_02_library.py").read(), ns)
ns["batch_crystals"](); ns["batch_jelly"]()   # ...
```

## Why scripts rather than saved scenes

The slicer imposes hard requirements on the geometry, and a script is the only
way to guarantee them across 53 assets:

- **Manifold, closed shells.** Cap generation only produces correct interior
  faces if the cut outline forms closed loops. Every builder composes
  primitives (`ico`, `cyl`, `cube`, `cone`, `torus`, `gem`, `slab`) that are
  closed by construction, joined without booleans — booleans are the fastest
  way to break manifoldness, so the pipeline never uses them.
- **Consistent outward normals.** `finalize()` recalculates them; the renderer
  back-face culls in world space and would punch holes in anything inconsistent.
- **Applied transforms and a predictable pivot.** Object space has to mean
  something to the physics, so `finalize()` applies location/rotation/scale and
  sets the origin to the bounds centre.
- **One material per colour section.** Sections are what the game matches to
  target pads, so each becomes its own glTF primitive and keeps its Blender
  name (`M_yellow`, `M_purple`, …). Levels refer to sections by that name.

## Style rules

The art bible is `icon.png`: faceted low-poly, chunky readable shapes, vibrant
colour sections, satin plastic and crystal, dark teal environment.

Encoded in the pipeline as:

- Low subdivision counts everywhere — icospheres at subdiv 1–2, cylinders at
  8–14 sides, gems at 5–8 facets.
- `flat_shade()` on every mesh; there is no smooth shading in the game at all.
- `bevel()` with 1–2 segments for the moulded-plastic read on toy and jelly
  pieces.
- Colours sampled from `icon.png` into `PALETTE`, converted sRGB → linear for
  Blender, then converted back to sRGB by the game's GLB loader.

## Nested shells are deliberate

Orbs, planets and fruit are built as *concentric closed shells* — a cyan crust
around a yellow mantle around a white core. Nothing of the inner shells is
visible until the player cuts, which is exactly what makes protected-core and
layered-planet levels work: the reveal is the reward for a good cut, and each
shell caps independently because the slicer walks one loop per shell.

## Export settings

`export_glb()` writes GLB with:

- Y-up (glTF convention), applied modifiers
- normals exported, no texcoords, tangents, cameras, lights, animation or skins
- materials exported, no textures — colour lives in `baseColorFactor`

The result is small: 53 models totalling 804 KB.

## Triangle budgets

| Class | Budget | Actual |
| --- | ---: | --- |
| Particle fragment | 300 | 12 |
| Small piece | 1,000 | 84–212 |
| Normal slicable object | 8,000 | 106–520 |
| Complex structure | 20,000 | 520 max |

The whole library is 11,324 triangles. Faceted low-poly is both the art
direction and the fastest thing for a flat-shaded software-transform renderer,
so the two pull in the same direction.

## 2D art from 3D assets

`render_art.py` imports the *shipped* GLB files and renders the six world
banners and the store icon. Menu art therefore cannot drift from what appears
in play.

Two settings matter and are easy to get wrong:

- **View transform must be `Standard`.** Blender defaults to AgX, which is
  built to tame photographic highlights and turns these flat vivid materials
  into pastel mush. The game renders in plain sRGB, so the art must too.
- **Sun lamps, not area lamps.** Sun intensity does not fall off with distance,
  so one set of values frames every asset regardless of its size.

## Regenerating the manifest
